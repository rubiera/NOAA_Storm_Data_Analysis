# Security Policy

## Supported Versions

This project is maintained on a best-effort basis.

The latest version on the `main` branch is considered the supported version and receives security-related updates when appropriate.

Older versions and forks may not receive security fixes.

| Version        | Supported |
| -------------- | --------- |
| main           | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public GitHub issue.

Instead:

1. Use GitHub's Private Vulnerability Reporting feature if available.
2. If Private Vulnerability Reporting is not available, contact the repository maintainer privately.
3. Include as much information as possible, including:

   * A description of the issue
   * Steps to reproduce
   * Potential impact
   * Any suggested mitigation

The maintainer will acknowledge receipt of the report and investigate the issue.

## Scope

Examples of security-related issues include:

* Exposure of credentials, API keys, or secrets
* Vulnerable project dependencies
* Insecure file handling
* Unsafe data download or processing workflows
* Supply-chain risks in build or deployment processes
* Vulnerabilities in GitHub Actions workflows

## Data Sources

This project may process publicly available NOAA data and other external datasets. Users should independently verify the integrity and provenance of downloaded data before use.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing any security vulnerability.

Thank you for helping improve the security of this project.
